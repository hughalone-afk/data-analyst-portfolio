# Coursework Reference

Walkthrough notebooks from IBM's "Data Analysis with Python" course, followed along on the
instructor-provided automobile-pricing dataset:

- `data_wrangling_review.ipynb`
- `exploratory_data_analysis_review.ipynb`
- `model_development_review.ipynb`
- `model_evaluation_review.ipynb`

These cover the same techniques used in the three main projects (missing-data handling, EDA,
regression, Ridge/polynomial models, Grid Search) but are instructor-led walkthroughs rather than
independent analysis — kept here as supporting evidence of course completion rather than presented
as portfolio projects. List the course itself under Education/Certifications on your CV; don't
submit these notebooks as standalone project work.
